# 📦 彩盒计价器

自动计算彩盒（瓦楞盒）报价的小工具。

## 使用方法

1. 打开 `index.html`（双击即可在浏览器中打开）
2. 填入刀版尺寸、面纸参数、浪纸参数
3. 选择印刷色数，勾选需要的后道工序
4. 选择运费区域，填入订单数量和利润点数
5. 实时显示最终报价和费用明细

## 计价逻辑

- **印刷机台**：根据面纸尺寸自动匹配最优机台
- **模切机台**：根据面纸尺寸自动匹配最优机台
- **糊盒**：固定使用瓦楞盒计价标准
- **后道工序**：覆膜、上油、压纹、烫金/银、开窗贴片、裱瓦，按需勾选
- **刀版费**：默认计算，可勾选排除
- **利润**：默认 15%，可手动调整

## 技术

纯前端 HTML + CSS + JavaScript，无需安装，浏览器打开即用。
